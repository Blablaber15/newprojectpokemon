# 🐉 Pokémon Battle Bot ⚔️

> **Создай своего покемона. Прокачивай его. Сражайся с другими. Стань лучшим тренером! 🔥**

Добро пожаловать в **Pokémon Battle Bot** — Telegram-бота, где каждый пользователь может получить собственного покемона и отправиться навстречу приключениям! 🚀

## 🎮 Что умеет бот?

✨ **Создание покемона**
Используй `/go` и получи своего уникального покемона 🎁
Имя, изображение, здоровье и сила определяются автоматически.

⚔️ **Сражения**
Брось вызов другому тренеру с помощью `/attack` 💥
Отвечай на сообщение соперника и начинай битву!

🍖 **Кормление**
Покемон тоже хочет кушать! 😋
Используй `/feed`, чтобы восстановить здоровье своего покемона.

📊 **Информация**
Команда `/info` покажет характеристики твоего покемона:

🗑️ **Удаление покемона**
Используй `/delete`, чтобы удалить своего текущего покемона 💔

После удаления ты сможешь снова использовать `/go` и создать нового покемона 🐣✨


* ❤️ Здоровье
* 💪 Сила
* 🏷️ Имя
* 🎭 Класс

## 🧙 Классы покемонов

В игре есть разные типы персонажей!

### 🧙 Wizard

**Волшебник** получает больше здоровья при кормлении ✨

> Магия — это сила! 🔮

### ⚔️ Fighter

**Боец** способен использовать специальную супер-атаку 💥

> Больше силы — больше разрушений! 🔥

## 🕹️ Команды

| Команда   | Действие                     |
| --------- | ---------------------------- |
| `/go`     | 🐣 Создать покемона          |
| `/info`   | 📊 Посмотреть характеристики |
| `/feed`   | 🍖 Покормить покемона        |
| `/attack` | ⚔️ Атаковать соперника       |

## 🌐 Pokémon API

Для получения информации и изображений покемонов используется **PokéAPI** 🌍

Бот получает данные о покемоне через API и автоматически загружает его изображение и имя.

## 🧠 Немного ООП

Проект использует **классы и наследование**:

```text
           🐉 Pokemon
           /       \
          /         \
    🧙 Wizard     ⚔️ Fighter
```

`Wizard` и `Fighter` наследуются от основного класса `Pokemon`, но изменяют поведение некоторых методов.

## 🚀 Как начать?

1. Установи зависимости 📦
2. Добавь токен Telegram-бота 🔑
3. Запусти `main.py` ▶️
4. Открой своего бота в Telegram 💬
5. Напиши `/go`
6. Получи своего покемона 🐉
